# 1,024-cell SUM qualification, 2026-11-02

JUN-704 extends the earlier cross-page formula evidence with a synthetic sparse
sheet containing 1,024 numeric cells and `=SUM(A1:A1024)`. The fixture was built
independently from framed workbook data; the expected result is 1,024.

- `check-workbook-formula.py` returned the expected result using the Amu
  selfhost native runner and Chrome Wasm with a 25,000,000 fuel budget. The
  regular formula fixture and column-index mutation control also passed.
- `check-workbook-large.py` loaded the same scale of SUM through the actual
  browser candidate UI, displayed `1024`, and preserved the input snapshot
  byte-for-byte. Its earlier off-screen edit, reload and other-sheet checks
  also passed.

The browser candidate was the build with Wasm SHA-256
`7cf8da6878e0651c715301940fd958e721a0f00058efd8979684ad867165eaec`,
compiled by selfhost candidate SHA-256
`2c551579c06a0228029bb06bae177e93126ecbbc37d636d693c471dbac8d1536`.
Chrome was version 156.0.8078.74. This tests one numeric input shape in a
synthetic local session, not all supported formulas or the 4,096-cell scan
limit; real migration, physical IME, QEMU, fleet and delivery remain open.
